# JoyCheck

JoyCheck è il programma gratuito di EnjoyTheBoost per controllare il PC: temperature, componenti e una prova sotto sforzo, per capire se il tuo computer sta bene.

**Scarica l'ultima versione:** [Releases](../../releases/latest) → `JoyCheck.exe`

Funziona su Windows 10 e 11, senza installazione: scarichi il file e lo apri.

## Avviso di Windows

Il file non è ancora firmato, quindi Windows può mostrare un avviso blu ("Windows ha protetto il PC"). Clicca su **Ulteriori informazioni**, poi su **Esegui comunque**.
